## Обновление 1.5.3

- Из механизма обновления удалена ненужная поддержка старых ZIP-пакетов Tauri v1 и связанные зависимости.
- Обновления продолжают устанавливаться через подписанный EXE. HTTPS и поддержка системного прокси сохранены.

Windows x64. Обновление внутри приложения подписано; подпись издателя Windows (Authenticode) пока отсутствует.

## Update 1.5.3

- Removed unused support for legacy Tauri v1 ZIP update bundles and its dependencies.
- Updates continue to use signed EXE installers. HTTPS and system proxy support are retained.

Windows x64. In-app updates are signed; Windows publisher signing (Authenticode) is not yet available.
