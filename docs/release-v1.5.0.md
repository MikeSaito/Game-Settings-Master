# Game Settings Master v1.5.0

Новый интерфейс в стиле Material 3 с темной и светлой темами.

- Компактная шапка игры и вкладки оставляют больше места настройкам. Сведения о GPU, папке конфигов и вариантах запуска доступны по кнопке информации.
- Описание параметра открывается по кнопке рядом со значением. Постоянная боковая панель больше не занимает место в редакторе.
- Сохранение пресета открывается в отдельном окне. Поля прокручиваются, кнопка сохранения остается видимой. Доступны выбранные правки и полный профиль редактируемых настроек.
- Обновлено оформление библиотеки, INI-файлов, управления, пресетов и резервных копий. Переключатель темы доступен в боковой навигации.
- Улучшена навигация с клавиатуры и работа диалогов. Предпросмотр повторного применения настроек открывается поверх сведений об игре.
- Сообщения диагностики об измененных настройках, ошибки проверки и конфликты остаются видимыми в рабочем пространстве.

Доступен установщик для Windows x64. Подпись обновления Tauri проверяет целостность пакета; подписи издателя Windows у установщика нет.

## English

A refreshed Material 3 inspired interface with dark and light themes.

- A compact game header and tabs give settings more room. GPU selection, configuration paths and launch options are available in game details.
- Parameter descriptions open from an information button instead of occupying a permanent side pane.
- Preset saving uses a separate dialog with scrolling fields and a visible save action. Both selected edits and full editable profiles remain available.
- Updated library, INI text editor, input bindings, presets and backup surfaces. A theme toggle is available in the navigation rail.
- Improved keyboard navigation and modal behavior, including diagnostic reapply previews above game details.
- Changed diagnostics, validation errors and setting conflicts remain visible in the workspace.

Windows x64 installer. The Tauri update signature verifies package integrity; the installer does not have a Windows publisher signature.
